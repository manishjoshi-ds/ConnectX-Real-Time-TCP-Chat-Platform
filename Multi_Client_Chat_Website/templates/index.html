A real-time client-server chat system built with Flask and Flask-SocketIO over WebSocket/TCP, supporting simultaneous users, public broadcasts, and confidential 1-to-1 private messaging.

Core Capabilities

01. Concurrent Multi-Client Room

Multiple clients such as Rahul, Aman, and Priya connect simultaneously and broadcast instant messages to the shared room.

02. Private 1-to-1 Routing

Select any online user from the sidebar to route encrypted-channel private messages directly via their socket session ID.

03. Duplicate & Empty Guards

Server-side validation rejects blank messages, malformed names, and duplicate active usernames before state mutation.

How It Works

1. TCP Handshake

The browser initiates a reliable 3-way TCP handshake (SYN, SYN-ACK, ACK) with the server port.

2. WebSocket Upgrade

An HTTP Upgrade request transitions the socket into a persistent full-duplex WebSocket frame stream.

3. Client Registration

Joining sends a join_chat event; the server registers the username and socket ID under a thread lock.

4. Real-Time Dispatch

Public messages broadcast to all clients; private messages emit strictly to the recipient socket ID.

Computer Networks Summary

Socket.IO over TCP vs Raw Python Sockets: A raw Python socket server binds directly to OS TCP streams using SOCK_STREAM and requires custom message framing. Web browsers cannot open raw TCP sockets directly due to security sandboxing, so Flask-SocketIO upgrades HTTP over TCP into WebSocket connections, preserving TCP's reliable, ordered byte-stream delivery while adding event multiplexing and heartbeat disconnection detection.
